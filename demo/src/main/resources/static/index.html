Spring Boot API Generator

Generador de Código Spring Boot

Este servicio genera un proyecto Spring Boot completo a partir de tu esquema de base de datos.

POST /api/generate/springboot

Cuerpo: JSON con esquema de base de datos { tables: [...], relationships: [...] }

Retorna: archivo ZIP con proyecto Spring Boot completo

Exportación de Datos

Descarga todos los canvases y archivos públicos en formato ZIP:

Descargar ZIP completo

GET /api/export/download

Retorna: archivo ZIP con canvases.json y /public

Importación de Datos

Sube un archivo ZIP con canvases.json y archivos para /public:

POST /api/export/upload

Cuerpo: form-data con campo 'file' conteniendo ZIP

Retorna: JSON con número de elementos importados

API REST Canvas

Endpoints disponibles para gestionar canvases:

  • GET /api/canvases - Lista todos los canvases
  • GET /api/canvases/{id} - Obtiene un canvas por ID
  • POST /api/canvases - Crea un nuevo canvas
  • PUT /api/canvases/{id} - Actualiza un canvas
  • DELETE /api/canvases/{id} - Elimina un canvas
